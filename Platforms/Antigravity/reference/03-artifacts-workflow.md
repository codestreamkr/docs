# 03. 아티팩트 기반 작업과 피드백

단순한 터미널 기반 도구에서는 긴 계획서나 분석 결과가 터미널 스크롤 위로 밀려나 찾기 어려워져요.  
Antigravity는 세션과 독립적으로 유지되는 구조화된 산출물인 아티팩트(Artifacts) 시스템과 실시간 코드 리뷰 기능을 지원해요.

이 문서는 Antigravity CLI `1.2.9`를 기준으로 해요.

## 1. 아티팩트(Artifacts)의 개념

아티팩트는 에이전트가 생성하는 독립적인 Markdown 문서예요.

- **휘발되지 않는 정본**: 대화가 길어져 컨텍스트가 압축(`compact`)되거나 요약되더라도, 아티팩트에 기록된 계획과 사양은 온전히 보존돼요.
- **시각화 지원**: Markdown 본문뿐만 아니라 Mermaid 다이어그램(시퀀스, 플로우차트, 클래스 다이어그램)을 내장해 호출 흐름과 설계를 직관적으로 파악할 수 있어요.
- **Playbook 연계**: 1단계에서 작성된 계획 아티팩트의 경로를 2단계 구현 Skill(`ct-code-spring`)에 전달해 일관된 기준으로 개발할 수 있어요.

## 2. 코드 변경 검토와 `/diff`

Antigravity CLI는 파일 변경 사항을 안전하게 확인하고 즉각 교정할 수 있는 리뷰 환경을 제공해요.

```text
/diff
```

### 인라인 피드백 작성 (`c` 키)

1. 세션 중에 `/diff`를 입력해 현재 변경 내용을 확인해요.
2. 수정이 필요한 특정 코드 라인에서 `c` 키를 눌러 인라인 코멘트를 입력해요.
3. 코멘트를 전송하면 에이전트가 해당 지적 사항을 반영해 코드를 즉시 재수정해요.

이 방식은 잘못 작성된 코드를 일일이 대화로 설명하는 수고를 덜어주고 변경의 정밀도를 높여줘요.

## 3. 실전 권장 워크플로

1. `/plan` 또는 `ct-plan-work`로 구현 계획 아티팩트를 먼저 생성해요.
2. 사용자 인터뷰나 계획 검토 버튼으로 계획을 확정해요.
3. 구현 진행 중 변경 사항은 `/diff`로 확인하며 필요한 라인에 바로 피드백(`c`)을 전달해요.
4. 검증이 완료되면 `ct-docs-impl`을 호출해 최종 코드 정본 문서를 아티팩트 또는 프로젝트 문서로 남겨요.
