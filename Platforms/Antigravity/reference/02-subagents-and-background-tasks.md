# 02. 서브에이전트와 백그라운드 태스크

독립된 조사·검증·구현은 Custom subagent로 나눠 진행할 수 있어요.  
이 문서는 2026-10-01에 설치된 Antigravity CLI `1.2.9`과 공식 Subagents 문서를 기준으로 해요.

## 1. Subagent를 사용할 때

서브에이전트는 메인 대화와 분리된 맥락에서 특정 역할을 수행해요.  
다음처럼 결과가 독립적인 작업을 나눌 때 사용해요.

- 서로 다른 모듈의 영향 범위를 조사해요.
- 문서 근거와 코드 근거를 따로 검증해요.
- 긴 작업을 수행하는 동안 메인 세션에서 다른 결정을 계속해요.

같은 파일을 동시에 수정할 가능성이 있으면 작업 범위와 담당 파일을 먼저 나눠요.

## 2. 세션에서 확인하기

열린 CLI 입력창에서 `/agents`를 사용해 에이전트를 전환하고, 백그라운드 서브에이전트의 상태를 확인해요.  
작업이 끝나면 결과 파일, 확인한 근거와 남은 항목을 메인 작업에 전달하도록 요청해요.

```text
주문 API와 결제 API의 호출 흐름을 각각 서브에이전트로 조사해줘.
근거 파일과 미확인 항목을 보고해줘.
파일은 수정하지 마.
```

`/agents`로 진행 상태를 확인하세요.  
백그라운드 명령의 로그 확인과 중지는 `/tasks`에서 진행해요.

장기 협업 작업은 `/teamwork-preview <작업>`으로 시작할 수 있어요.  
이 명령의 제공 여부는 요금제와 현재 세션에 따라 다르므로 `/help`에서 확인해요.

## 3. Custom subagent 정의

Custom subagent는 역할·도구·지침을 정의해 재사용할 수 있어요.  
Plugin으로 배포하면 여러 프로젝트나 팀에서 같은 정의를 공유할 수 있어요.  
정의 위치와 현재 사용 가능한 에이전트는 공식 문서와 `/agents`를 기준으로 확인해요.
