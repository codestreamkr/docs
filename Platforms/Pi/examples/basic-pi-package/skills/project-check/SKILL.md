# 프로젝트 점검

현재 작업 디렉터리를 프로젝트 루트로 보고 읽기 전용 점검을 수행한다.

## 확인 절차

1. `README*`, `package.json`, 빌드 파일, wrapper, CI 설정 파일을 찾는다.
2. 기술 스택과 주요 디렉터리를 확인한다.
3. 파일에 실제로 정의된 실행·빌드·테스트·린트 명령만 추출한다.
4. 변경 전에 먼저 읽어야 할 파일과 주의할 설정을 정리한다.

## 실행 기준

- 조회 명령만 실행한다.
- 의존성 설치, 빌드, 테스트, 린트는 사용자가 요청한 경우에만 실행한다.
- 파일을 수정하지 않는다.
- 확인되지 않은 명령은 추정하지 않고 `확인 필요`로 표시한다.

## 출력 형식

- 기술 스택
- 주요 디렉터리
- 실행 명령
- 검증 명령
- 우선 확인 파일
- 확인 필요 사항
