# 02. 서브에이전트와 백그라운드 태스크

대규모 프로젝트에서는 수많은 파일을 읽고 장시간 빌드나 테스트를 실행해야 해요.  
Antigravity는 메인 대화창의 토큰 컨텍스트를 오염시키지 않으면서 복잡한 작업을 비동기로 처리할 수 있는 하위 실행 구조를 제공해요.

이 문서는 Antigravity CLI `1.2.9`를 기준으로 해요.

## 1. 서브에이전트 (Subagents)

서브에이전트는 메인 에이전트로부터 특정 업무를 위임받아 독립된 대화 궤적(Trajectory)에서 실행되는 별도 에이전트예요.

### 왜 서브에이전트를 쓰나요?

- **컨텍스트 오염 방지**: 수십 개의 파일을 검색하고 분석하는 과정에서 발생하는 대량의 텍스트가 메인 세션에 남지 않아요.
- **역할 분담**: 읽기 전용 조사 에이전트, 코드 수정 에이전트 등 도구 권한을 작업 목적에 맞게 제한할 수 있어요.
- **병렬 분석**: 서로 다른 패키지나 모듈을 복수의 서브에이전트에 동시에 맡겨 분석 속도를 높일 수 있어요.

### 기본 제공 서브에이전트 유형

| 유형 | 권한 및 도구 | 주요 용도 |
| --- | --- | --- |
| `research` | 읽기 전용 (코드 검색, 웹 검색, 파일 읽기) | 넓은 범위의 코드베이스 탐색, 공식 문서 조사 |
| `self` | 메인 에이전트의 전체 도구와 시스템 프롬프트 상속 | 별도 컨텍스트에서 구현 및 리팩토링 수행 |

사용자가 직접 위임하거나, 메인 에이전트가 작업 규모를 판단해 스스로 서브에이전트를 구동해요.

## 2. 백그라운드 태스크 (Background Tasks)

Gradle 빌드, 컨테이너 기동, 전체 테스트 스위트 실행처럼 수 분 이상 걸리는 작업은 백그라운드 태스크로 전환돼요.

### 반응형 깨우기 (Reactive Wakeup)

- **폴링 루프 불필요**: 상위 에이전트가 명령이 끝났는지 주기적으로 확인(`sleep`이나 `status` 반복)할 필요가 없어요.
- **자동 알림 재개**: 백그라운드 작업이 완료되거나 특정 출력이 발생하면 시스템이 에이전트를 자동으로 깨워 후속 작업을 진행하도록 해요.
- **비차단 작업**: 백그라운드 태스크가 돌아가는 동안 사용자와 에이전트는 다른 파일 검토나 계획 수립을 계속할 수 있어요.

## 3. 실전 활용 팁

- 대규모 호출 구조 분석(`ct-code-tree`)을 요청할 때는 "서브에이전트로 조사해서 요약만 알려줘"라고 지정하면 메인 대화 세션의 토큰을 대폭 절약할 수 있어요.
- 시간이 오래 걸리는 테스트 실행(`ct-code-tree-test`) 시 백그라운드로 넘겨 두고 다른 기능 설계를 병행해요.
