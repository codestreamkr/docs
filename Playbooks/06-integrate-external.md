# 외부 서비스 연동하기

공급자 계약과 내부 계약을 분리해 확인한 뒤 단계적으로 연동하거나 이관해요.

## 흐름

```text
ct-plan-ext       공급자 계약, 데이터 매핑과 실패·이관 조건 확인
      ↓
ct-plan-work      내부 변경 순서와 완료 조건 확정  ← 단계별 구현이 필요할 때
      ↓
ct-code-spring    확정된 범위 구현
      ↓
ct-qa-flow        중복 요청, 지연, 실패와 병행 경로 검증
```

## 다음 단계로 넘어갈 기준

- 공급자의 현재 인증·요청·응답 계약을 공식 자료에서 확인해요. 미확인 사항은 추정으로 채우지 않아요.
- 내부 데이터 매핑, 상태의 정본, 재시도·멱등성 기준을 확정해요.
- 공급자를 바꾼다면 이관 순서, 병행 운영의 비교 기준과 롤백 조건을 정해요.
- 확정된 범위만 구현하고 중복 요청, 타임아웃과 실패 후 재처리 경로를 검증해요.
- 공급자 측 미확인 사항과 검증하지 못한 범위를 남겨요.

## 다른 흐름을 쓸 때

외부 공급자는 그대로이고 내부 구조만 바꾸면 [05 구조 전환하기](./05-transition-structure.md)를 사용해요.
