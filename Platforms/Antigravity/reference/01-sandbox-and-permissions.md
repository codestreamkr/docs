# 01. 터미널 샌드박스와 권한 정책

Antigravity CLI(`agy`)는 로컬 머신의 파일 시스템과 셸 명령에 직접 접근할 수 있는 강력한 코딩 에이전트예요.  
작업 생산성을 높이면서도 의도치 않은 시스템 손상을 방지하기 위해 샌드박스와 실행 권한 모드를 제공해요.

이 문서는 Antigravity CLI `1.2.9`를 기준으로 해요.

## 1. 터미널 샌드박스 (`--sandbox`)

에이전트가 신뢰할 수 없는 외부 코드를 다루거나 광범위한 리팩토링을 수행할 때 샌드박스를 켜서 호스트 시스템을 보호해요.

```bash
agy --sandbox
```

샌드박스가 활성화되면 다음과 같이 동작해요:

- **작업 영역 외 파일 보호**: 워크스페이스 외부 경로에 대한 임의 쓰기나 시스템 설정 파일 수정을 제한해요.
- **명령 격리**: 시스템에 치명적인 영향을 줄 수 있는 비가역적 명령어 실행을 사전에 차단하거나 확인을 요구해요.
- **안전한 빌드/테스트**: `ct-run-script` 등으로 생성된 스크립트를 로컬 머신 오염 없이 안전하게 검증할 수 있어요.

## 2. 세 가지 실행 모드 (Mode)

작업 상황에 따라 에이전트의 자율 실행 범위를 조정해요.

| 실행 모드 | 주요 동작 | 적합한 작업 |
| --- | --- | --- |
| **Auto mode** | 안전한 파일 읽기/편집과 기본 명령어 실행을 자동 승인해요 | 일상적인 기능 구현, 버그 수정, 테스트 실행 |
| **Interactive mode** | 파일 수정이나 명령 실행마다 사용자의 직접 확인과 승인을 받아요 | 민감한 설정 변경, 외부 배포 스크립트 실행 |
| **Plan mode** | 코드를 수정하지 않고 오직 분석과 계획 아티팩트만 작성해요 | 대규모 구조 전환 전 영향 평가, 아키텍처 검토 |

CLI 시작 시 모드를 지정할 수 있어요:

```bash
agy --mode plan
agy --mode accept-edits
```

실행 중인 TUI 화면에서는 `Shift+Tab`을 눌러 언제든지 모드를 순환 전환할 수 있어요.

## 3. 권한 건너뛰기 (`--dangerously-skip-permissions`)

모든 도구 실행 권한 요청을 묻지 않고 자동 승인해요.

```bash
agy --dangerously-skip-permissions
```

- **권장 환경**: 격리된 Docker 컨테이너, 임시 CI/CD 러너 등 시스템 손상 위험이 없는 독립 환경에서만 사용해요.
- **로컬 개발 권장**: 로컬 머신에서는 이 플래그 대신 기본 Auto mode(`Shift+Tab`)나 세부 승인 정책을 사용하는 것이 안전해요.
