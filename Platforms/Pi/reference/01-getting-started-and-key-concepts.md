# 01. [초급] Pi 시작하기

Pi 1.x 공식 문서 기준으로 첫 세션부터 작은 작업까지 실습해요.  
설치와 인증은 [환경 설정](../setup.md)을 먼저 완료하세요.

## 1. 프로젝트 열기

터미널에서 프로젝트 폴더로 이동해 실행하세요.

```bash
cd /path/to/project
pi
```

프로젝트 자원의 신뢰 여부를 물으면 `.pi/`와 `.agents/skills/` 내용을 확인한 뒤 결정하세요.  
신뢰 설정은 파일 접근을 격리하지 않아요.

## 2. 첫 요청 보내기

Pi 채팅창에서 구조와 테스트 방법을 확인하세요.

```text
이 저장소의 구조와 테스트 명령을 근거 파일과 함께 알려줘.
파일은 수정하지 마.
```

현재 작업 루트와 읽은 파일을 응답에서 확인하세요.

## 3. 작은 작업 실행하기

범위와 완료 조건을 함께 지정하세요.

```text
README의 실행 방법이 실제 빌드 설정과 일치하는지 확인해줘.
불일치한 명령만 수정하고 근거 파일을 알려줘.
```

변경 파일과 검증 결과를 확인하세요.
