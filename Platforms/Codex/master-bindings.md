# Codex에서 Masters 사용하기

Codex에서는 자연어로 Master를 부르면 등록된 Skill이 해당 역할을 수행한다.

Master의 성격, 입력과 완료 기준은 [Masters](../../Masters/README.md)를 정본으로 사용한다. 이 문서는 Codex Skill과의 연결만 관리한다.

## 연결표

현재 Codex 환경에 등록된 이름을 기준으로 연결한다.

| Master | 공통 역할 | Codex Skill | 자연어 호출 예시 |
| --- | --- | --- | --- |
| 잡스형 | 서비스·제품 기획 | `pd` | `잡스형, 기능 범위를 정리해줘.` |
| 대부님 | 쿼리 튜닝 | `query-tuner` | `대부님, 실행 계획을 분석해줘.` |
| 로드형 | Spring 개발 | `spring` | `로드형, 이 API를 구현해줘.` |
| 호페형 | 외부 연동 설계 | `external-architect` | `호페형, 결제 연동 구조를 검토해줘.` |
| 루신 | QA와 회귀 검증 | `qa-lucin` | `루신, 이 기능의 위험을 찾아서 검증해줘.` |

## 호출 기준

Master 이름과 필요한 결과를 함께 말한다.

```text
호페형, 기존 PG와 신규 PG의 병행 운영 구조를 설계해줘.
현재 상태, 목표 상태, 전환 단계와 롤백 기준이 필요해.
```

```text
루신, 로드형이 구현한 주문 취소 기능을 검증해줘.
권한, 중복 요청과 외부 PG 지연을 우선 확인해줘.
```

Skill 이름을 직접 지정해야 할 때만 `$skill-name` 형식을 사용한다.

## 확인 기준

현재 세션에 Skill이 제공되었는지 확인한 뒤 실행한다.

- Skill 목록에 대상 이름이 있다.
- 자연어 트리거와 역할이 연결되어 있다.
- 필요한 도구와 권한을 사용할 수 있다.
- 결과가 공통 Master 문서의 완료 기준을 충족한다.
